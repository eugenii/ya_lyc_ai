### 5 Самый популярный актёр

Необходимо определить, какой актёр встречается в фильмах подборки чаще всего.

Формат вывода
Имя актёра. Оно может состоять из одного или нескольких слов, разделенных пробелом. Регистр и имя – в точности как в датасете, например Леонардо ДиКаприо

Примечания
Рекомендуем воспользоваться вспомогательной функцией split_col или написать свою, так как в датасете актёры представлены в таком виде:

0    Тим Роббинс; Морган Фриман; Боб Гантон; Уильям...
1    Том Хэнкс; Дэвид Морс; Бонни Хант; Майкл Кларк...```

Сама функция:
```python
def split_col(s):
    s = s.fillna("")
    s = s.astype(str)
    s = s.str.split(";")
    s = s.apply(lambda lst: [x.strip() for x in lst if x.strip()])
    return s 
```
Функция принимает столбец DataFrame и для каждой ячейки:

заменяет пропуски (NaN) на пустую строку
приводит значение к строке
разбивает строку по символу ";"
убирает лишние пробелы
удаляет пустые элементы.
